TOOLKIT PLAN - Python Toolkit
=============================

1. TOOLS AND WHAT EACH ONE DOES
-------------------------------
Tool 1 - Number Guessing Game: The computer picks a secret number from 1 to 20 and I get 6 tries to guess it, with "too high" / "too low" hints.
Tool 2 - To-Do List: I can add tasks, remove tasks by number and view my list, and the list is kept while the toolkit is running.
Tool 3 - Simple Calculator: I enter two numbers and an operator (+, -, *, /) and it prints the result, without crashing on bad input or dividing by zero.
Tool 4 - Name Formatter: I type my name in any messy capitalisation and it shows it neatly formatted, with my initials and the number of letters.

3. CONCEPTS EACH TOOL WILL USE
------------------------------
Menu loop:        while loop, if / elif / else, f-strings
Guessing Game:    random module, while loop, if / elif / else, counter variable, f-strings
To-Do List:       list (append, pop, len), while loop, for loop with numbering, if / elif / else, f-strings
Calculator:       if / elif / else on the operator, try / except for bad numbers, f-strings
Name Formatter:   string methods (.strip, .title, .split), for loop to build initials, len(), f-strings
